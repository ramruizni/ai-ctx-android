# Setup Navigation

Create navigation routes and graphs for the feature.

## Usage
```
/setup-navigation [feature-name]
```

## Workflow

I will create the navigation infrastructure for your feature following Navigation Compose patterns.

### Step 1: Analyze Navigation Requirements
I will:
- Examine the feature screens and flow
- Determine if new routes are needed
- Check if a separate navigation graph is required
- Identify navigation parameters and arguments

### Step 2: Design Navigation Structure
I will:
- Analyze the feature's screen flow and navigation needs
- Propose route definitions and navigation graph structure
- Identify required navigation parameters and their types
- Determine integration strategy with existing navigation

### Step 3: Present Navigation Plan for Approval
I will:
- **PAUSE FOR APPROVAL**: Present the proposed navigation structure
- Show you the route definitions I plan to create
- Explain the navigation graph organization
- Detail any parameters and navigation arguments
- **Wait for your confirmation or modifications**

### Step 4: User Approval
Before creating navigation components, I will show you:
1. **Proposed Routes** - Route names, paths, and parameters
2. **Navigation Graph Structure** - How routes will be organized
3. **Integration Strategy** - How it connects to existing navigation
4. **Navigation Arguments** - What data will be passed between screens

You can then:
- Approve the navigation structure
- Request different route names or organization
- Modify navigation parameters
- Suggest alternative navigation flows

### Step 5: Create Navigation Components (After Approval)
I will:
- Create route objects/sealed classes with approved structure
- Add routes to appropriate navigation graph
- Configure navigation arguments and types
- Update navigation host with new routes

### Step 6: Screen Integration
I will:
- Wire up composable screens with navigation
- Add navigation callbacks to screens
- Handle back navigation and deep links

## Approval Process:
I will present:
- Route structure and naming
- Navigation graph organization
- Parameter definitions
- Integration points with existing navigation
